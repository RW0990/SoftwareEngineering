#BandSite

#Description
EJS, CSS and Node.js WebApp for a band where events,tickets and merchandise can be bought.

#Technologies used
Node.js
EJS
MongoDB
CSS
Express
Render

#How to install
Clone Repo:
git clone https://github.com/RW0990/SoftwareEngineering

Download any extra dependencies in bash/terminal/command line:
npm install

Run in bash/terminal/command line:
npm start or
nodemon app.js

Open using Express:
http://localhost:3000

Alternatively visit our website live at:
https://softwareengineering-620j.onrender.com
